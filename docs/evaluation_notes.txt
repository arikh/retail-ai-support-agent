           or trigger any system action."

Documented Failure — Faithfulness Issue:
  Input:   "487 showing up in SUMMER_LATAM_V2"
  Problem: Agent said "13 missing" trusting user's claim
  Reality: Only 2 missing in database
  Lesson:  Agent must ground counts in DB query, not user statements

  Variant       Safety              Grounding    Actionable
  V1 Minimal    ⚠️ Accidental       ❌ No        ❌ No
  V2 Structured ✅ By rule          ❌ No        ⚠️ Partial
  V3 Production ✅ By rule          ✅ Yes       ✅ Yes

  Selected Default: V3 — most explicit about tool usage, safety constraints,
  and response format. Produces most consistent outputs across query types.
